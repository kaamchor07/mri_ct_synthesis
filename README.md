## 🧠 What & Why

Traditional radiation therapy planning requires a **CT scan** to calculate radiation
dose distributions (because CT provides tissue density / Hounsfield Units directly).
However, many patients already have an **MRI scan** for soft-tissue diagnosis.
Requiring a separate CT exposes the patient to additional ionizing radiation.

**Synthetic CT (sCT)** generation from MRI addresses this: if we can train a deep
learning model to generate a CT-equivalent image from an MRI, patients may only need
one scan — reducing radiation exposure and cost.

This is a **portfolio / research project** demonstrating two architectures:
1. **Baseline U-Net** — supervised learning with L1 loss
2. **pix2pix cGAN** — adversarial training for perceptually sharper outputs

## 🔬 Technical Approach

### Architecture

```
MRI slice (1, 256, 256)
       │
       ▼
┌─────────────────────────────────────┐
│          U-Net Generator            │
│  Encoder: 1→64→128→256→512 (×4)    │
│  Bottleneck: 512→512                │
│  Decoder: 512→256→128→64 (×4)      │
│  Skip connections at each level     │
│  Output: tanh → [−1, 1]            │
└─────────────────────────────────────┘
       │
       ▼
Synthetic CT slice (1, 256, 256)

pix2pix also adds:
┌─────────────────────────────────────┐
│        PatchGAN Discriminator       │
│  Input: MRI + CT concat (2ch)       │
│  4×Conv (stride 2) → patch scores  │
│  Receptive field: ~70×70 pixels     │
└─────────────────────────────────────┘
```

### Training

| Setting | Value |
|---------|-------|
| Input size | 256 × 256 px |
| Batch size | 8 |
| Optimizer | Adam (lr=2e-4, β₁=0.5) |
| Baseline loss | L1 |
| pix2pix G loss | 100 × L1 + BCE(D(mri, fake_ct), 1) |
| pix2pix D loss | BCE(D(mri, real_ct), 1) + BCE(D(mri, fake_ct), 0) |
| Epochs | 50 |
| Data split | 70% train / 15% val / 15% test (by patient) |

### Dataset

[SynthRAD2023](https://synthrad2023.grand-challenge.org/) — ~180 paired MRI + CT
brain cases, pre-registered. See [`data/README.md`](data/README.md) for download
instructions.

## ⚠️ Limitations & Ethics

### Technical limitations
- Trained on **brain** data only — will not generalize to other body regions.
- 2D slice-by-slice inference: no 3D volumetric consistency enforced.
- May hallucinate fine bone structures that differ from the true CT.
- Performance depends heavily on MRI protocol; tested on T1-weighted only.

### Ethical statement
> **This is NOT a clinical tool.** It has not been validated for medical diagnosis,
> radiation therapy planning, or any clinical use. Synthetic CT images **may contain
> structural errors or hallucinations** that could lead to incorrect medical decisions
> if misused. All outputs should be treated as research demonstrations only.

The SynthRAD2023 dataset is used under its research license and credited
to Thummerer et al. (2023).

## 🚀 How to Run

### 1. Prerequisites

- Windows 10/11
- Python 3.10+
- NVIDIA GPU with CUDA (recommended; CPU fallback available but slow)

### 2. Clone & install

```powershell
git clone https://github.com/YOUR_USERNAME/mri_ct_synthesis.git
cd mri_ct_synthesis

# Create and activate a virtual environment
python -m venv .venv
.venv\Scripts\activate

# Install PyTorch with CUDA 12.1 support (adjust URL for your CUDA version)
pip install torch==2.2.2 torchvision==0.17.2 --index-url https://download.pytorch.org/whl/cu121

# Install remaining dependencies
pip install -r requirements.txt
```

### 3. Download the dataset

Follow the detailed instructions in [`data/README.md`](data/README.md).

After downloading, your structure should be:
```
data/brain/
├── 1BA001/
│   ├── mr.nii.gz
│   └── ct.nii.gz
└── ...
```

### 4. Explore the data (optional but recommended)

```powershell
jupyter notebook notebooks/01_data_exploration.ipynb
```

### 5. Train the baseline U-Net

```powershell
python src/train_baseline.py --data_dir data/brain --epochs 50
```

Training log: `outputs/unet_training_log.csv`
Best weights: `checkpoints/unet_best.pth`

### 6. Train pix2pix

```powershell
python src/train_pix2pix.py --data_dir data/brain --epochs 50
```

Training log: `outputs/pix2pix_training_log.csv`
Best generator: `checkpoints/pix2pix_best.pth`

### 7. Evaluate

```powershell
# Evaluate pix2pix
python src/evaluate.py --checkpoint checkpoints/pix2pix_best.pth --model pix2pix

# Evaluate U-Net baseline
python src/evaluate.py --checkpoint checkpoints/unet_best.pth --model unet
```

Output figures: `outputs/eval_grid.png`, `outputs/failure_cases.png`

### 8. Run the Gradio demo

```powershell
python app/app.py --checkpoint checkpoints/pix2pix_best.pth
```

Open `http://localhost:7860` in your browser.
